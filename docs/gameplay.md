# Gameplay

Mission Forge is an educational simulation, not a professional spacecraft mission planner.

## Flow
Home → Destination → Mission brief → Objectives → Route choice & preview → Budget / Fuel / Power / Communications / Instruments → Mission overview → Craft preset → Hangar (build) → Launch check (readiness) → GO/NO-GO poll → Launch → Flight (orbit / chase / cockpit cameras, time warp) → Encounter (hazard decision) → Docking / Rescue (if failed) → Landing → Mission report.

## Real-world / scientific concepts
- Rocket equation Δv from real engine Isp values
- Inverse-square solar power
- NASA reference planetary data
- Live space weather (DONKI) feeding one GO/NO-GO station
- Live planet positions (JPL Horizons)

## Mission Forge game mechanics
These are our own design, not NASA data:
- Mission readiness score (1–100; any score allows launch)
- Science score and mission scoring
- Resource tradeoffs and component masses where not published
- Route multipliers and simplified transfer estimates
- Hazard events and gameplay damage
- Rescue scenarios and rescue-kit masses
- Mission outcomes
- Most GO/NO-GO station thresholds (not NASA flight rules)
